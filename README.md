# imrc_box_master

IMRCのロボット向け自動位置調整ノードです。

2D LiDARから取得した点群情報を利用し、
ステージ上の固定オブジェクトや壁との位置関係を推定し、
機体位置を自動調整します。

計算された位置誤差をPID制御し、
足回り制御ノードへ移動命令を送信します。

---

## 機能

- 2D LiDAR点群取得
- 壁・固定物体の近似計算
- 自己位置補正
- PID制御
- 足回り制御ノードへの移動指令送信

---

## システム構成

```text
[2D LiDAR]
      │
      ▼
[imrc_box_master]
      │
      ▼
[Foot Controller]
      │
      ▼
[Robot Movement]
````
